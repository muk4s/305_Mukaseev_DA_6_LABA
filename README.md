# Лабораторная работа №6

## Тема

Механизм внимания. Трансформеры. Реализация системы машинного перевода с высокоресурсного языка на малоресурсный.

В работе реализован перевод:

```text
ru -> myv
русский -> эрзянский
```

Для обучения используется корпус Hugging Face:

```text
slone/myv_ru_2022
```

## Запуск обучения

Команда запуска эксперимента:

```powershell
py -m nmt_lab.train --dataset-name slone/myv_ru_2022 --source-column ru --target-column myv --limit 10000 --epochs 200 --batch-size 64
```

## Примеры перевода

```text
ru:  простер облако в покров им и огонь, чтобы светить им ночью.
ref: азорось сравтсь пель израиленсетнень вельтямокс ды кучсь тол – кадык вест ули валдо.
hyp: азорось сравтсь пель израиленсетнень вельтямокс ды кучсь тол – кадык вест валдо
```

```text
ru:  ибо, во-первых, слышу, что, когда вы собираетесь в церковь, между вами бывают разделения, чему отчасти и верю.
ref: васняяк, мон маринь: тынк кемикуронь промкстнэсэ эрсить явновомат, ды аламодо кемангак тенень.
hyp: васняяк, мон маринь: тынк кемикуронь промкстнс эрси явновомат, ды аламодо кемангак тенень
```

```text
ru:  и все изумлялись и дивились, говоря между собою: сии говорящие не все ли галилеяне?
ref: весе прасть дивас ды талнозь кевкстнесть вейкест-вейкест: «нать весе неть ломантне аволь галилеянь эрицят?
hyp: прасть дивас ды талнозь кевкстнесть вейкест-вейкест: «нать весе неть ломантне аволь гали эрицят
```

Обозначения:

- `ru` - исходное предложение на русском языке;
- `ref` - эталонный перевод из корпуса;
- `hyp` - перевод, который сгенерировала обученная модель.

## Что такое BLEU

BLEU - это метрика качества машинного перевода. Она сравнивает перевод модели `hyp` с эталонным переводом `ref`.

Чем выше BLEU, тем больше совпадений между машинным и правильным переводом. В данном эксперименте итоговое значение `BLEU = 25.91`, что показывает приемлемое качество для базовой Transformer-модели на малоресурсном направлении `ru -> myv`.

## Как работает модель

В проекте используется архитектура Transformer encoder-decoder.

Encoder получает русское предложение и строит его внутреннее представление. Decoder по этому представлению генерирует перевод на эрзянском языке. Для учета порядка символов используется позиционное кодирование.

Главная часть Transformer -- механизм внимания. Он позволяет модели при генерации каждого токена перевода смотреть на разные части исходного предложения и выбирать наиболее важную информацию.

В decoder используется masked self-attention. Благодаря маске модель во время обучения не видит будущие токены перевода и учится генерировать текст слева направо.

## Основные этапы работы

1. Загружается параллельный корпус `ru -> myv`.
2. Тексты нормализуются и разбиваются на символы.
3. Формируются словари исходного и целевого языков.
4. Предложения превращаются в последовательности числовых токенов.
5. Transformer обучается предсказывать следующий токен целевого предложения.
6. После обучения модель сохраняется в checkpoint.
7. Для проверки выполняется greedy decoding: модель по одному токену генерирует перевод.
8. Качество оценивается через `valid_loss` и `BLEU`.
